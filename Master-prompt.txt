You are acting as a senior product architect, UX designer, full-stack engineer, database architect, and technical lead.

Your job is to DESIGN AND BUILD a polished DEMO healthcare marketplace / SaaS platform with B2C, B2B, and internal administration capabilities.

This is NOT intended to be production-ready healthcare software.

The purpose of this project is to create a convincing, functional, visually polished prototype that can be demonstrated to prospective clients.

If clients approve the concept, production compliance, security hardening, integrations, infrastructure, scalability, payment providers, logistics integrations, and regulatory requirements will be addressed separately.

The priorities for this project are:

1. Working end-to-end demo
2. Excellent UI/UX
3. Realistic interconnected demo data
4. Complete core business workflows
5. Clean code and architecture
6. Easy local setup
7. Extensibility
8. Production sophistication only where it does not slow down the demo

DO NOT over-engineer this project.

Do not introduce microservices, Kubernetes, Kafka, event sourcing, CQRS, Redis, Elasticsearch, distributed messaging, or other enterprise infrastructure unless absolutely required.

Use a modular monolith.

============================================================
1. PRODUCT CONCEPT
============================================================

Build a multi-tenant healthcare marketplace connecting:

B2C:
- Patients

B2B:
- Independent doctors
- Freelance doctors
- Small clinics
- Independent/non-corporate hospitals
- Pharmacies / drug stores

Internal:
- Platform employees
- Platform administrators
- Super administrators

The platform should allow healthcare providers to establish an online presence and reach customers/patients.

Patients should be able to:

- discover doctors
- discover clinics
- discover hospitals
- discover pharmacies
- book doctor consultations
- manage appointments
- receive prescriptions
- purchase medicines
- select their preferred pharmacy
- upload prescriptions
- order prescribed medicines
- receive medicine home delivery
- track orders
- maintain basic health records
- rate providers
- save favorite doctors and pharmacies

The platform must support multiple independent healthcare businesses using the same application.
